* `src/css/main.css`: removed the unused `--color-warning-bg` custom property. All remaining `var()` references resolve to a defined property.

* Subagent test count: a subagent reported "4 passed, 4 total" for `npm test`. The raw run showed 112 passed. The recorded count is the raw count.
