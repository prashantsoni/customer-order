## Contents

* `brds/`: business requirements and their assumptions, gaps, and risks
* `requirements/raw/`: original requirement input
* `requirements/refined/`: refined product requirements
* `decisions/`: durable design choices and their consequences
* `plan/`: implementation phases, progress, and requirement coverage
* `reviews/`: phase gate results, findings, and deferred risks

## Working With These Documents

The refined product requirements describe the agreed product behaviour. Decision records explain implementation choices; the implementation plan tracks phases and evidence. Read the relevant phase review when checking completed work or resuming a phase.
