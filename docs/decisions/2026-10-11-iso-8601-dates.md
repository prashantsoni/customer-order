## Status

Accepted, with inferred options and reason. Builder to confirm.

## Context

The data model stores `createdAt` and `updatedAt` ([PRD Data Model](../requirements/refined/customer-order-prd.md)). Display follows the user's locale ([GAP-15](../brds/customer-order-brd.md)).

## Options Considered

| Option                 | Summary                                            | Trade-offs                                                            |
|------------------------|----------------------------------------------------|-----------------------------------------------------------------------|
| ISO 8601 strings       | Text such as `2026-10-11T09:00:00Z`.               | Readable in storage. Independent of the user's locale.                |
| Epoch milliseconds     | A number of milliseconds since 1970. (Inferred option.) | Compact. Needs conversion to read in storage.                    |

## Decision

Store dates as ISO 8601 strings. Format them only at render time.

## Reason

The PRD states the storage format ([PRD Data Model](../requirements/refined/customer-order-prd.md)). Storage then does not depend on the user's locale. (Inferred.)

## Consequences

* Dates sort correctly as text.
* Display formats follow the user's locale ([D-27](2026-10-11-english-only-locale.md)).
